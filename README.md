# Portafolio web — Miguel Alexis Sánchez Carranza

Portafolio personal desarrollado para presentar mis proyectos, mostrar mis habilidades en desarrollo web y dar a conocer mis servicios.

El sitio web incluye información sobre mí, las tecnologías con las que trabajo y una selección de cuatro proyectos realizados para clientes, además de un proyecto propio: **QuickCart**, una tienda online de demostración integrada en el portafolio, con catálogo de productos, carrito de compras y flujo de pedidos simulado.

También cuenta con una sección para presentar mis servicios y medios de contacto para personas interesadas en trabajar conmigo.
